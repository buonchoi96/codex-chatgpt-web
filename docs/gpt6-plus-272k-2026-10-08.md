# Experimental 272K GPT-6 Sol Plus compaction — 2026-10-08

## Scope
- `chatgpt-web/gpt-6-sol` on **Plus**: Medium/High; also the separate Extra High effort only when the account explicitly exposes that effort.
- Codex catalog raw `context_window` and `max_context_window`: **320,000**.
- Codex `effective_context_window_percent`: **95** (304,000 effective *declared* tokens).
- Codex `auto_compact_token_limit`: **272,000** (was 80,000), with 32K declared headroom.
- Codex's 90% raw-window auto-compact clamp allows 288K and therefore does not silently reduce 272K.

## Important limitations
This is an **experimental local bridge/Codex catalog change only**. It does **not** change OpenAI's ChatGPT Plus entitlement, the real GPT-6 Sol backend context window, ChatGPT truncation behavior, or server-side per-message limits. Neither successful retention beyond 80K nor 272K real-context availability has been demonstrated for GPT-6 Plus. At the first server-side message/context rejection, stop the experiment and restore the earlier 90K/80K profile (or use a separately verified context strategy).

Keep unchanged: Plus Instant 41K/32K, Pro GPT-6 profiles and Bigger Context, GPT-5.6/Luna 1M profiles, the 500K-character GPT-6 Plus reasoning composer cap, staging/attachments, safety boundaries and model availability.

## Verification
Unit expectations in `tests/chatgpt-web-models.test.ts` and `tests/model-catalog.test.ts` cover the selected Plus route, exact compact target, effective headroom, Codex clamp, no unintended Pro/Instant/5.6 changes, and unchanged browser transport.

Run locally with the pinned Bun toolchain:

```powershell
bun test ./tests/chatgpt-web-models.test.ts ./tests/model-catalog.test.ts
bun run typecheck
```

An end-to-end acceptance test requires a real **Plus** GPT-6 Sol Web session with 80K+, then 160K+, then 272K staged cumulative input tokens, checking what the model can recall and when `/compact` fires. Do not interpret only the outer Codex context meter as evidence that the browser model actually retained the input.
